# 猫眼 Catseye：lolinet 的固定美学

一句话：**黑里只亮一点。** 纯黑虚空做底，全站只有一种强调色，像猫眼在暗处反的那一点绿光。
日间是同一套规则换成纸白底：**纸上只点一点。**

所有取值都在 [`src/styles/tokens.css`](src/styles/tokens.css)，活样张在控制台的 `#/design` 页。
改 token 之后先到样张页看一遍；组件里不写死颜色、字号、圆角和时长。

## 从哪来

| 参考 | 取什么 | 不取什么 |
|---|---|---|
| [uwu.cat](https://uwu.cat/) | 纯黑底；灰色星号标志；彩色光标群（多人光标的「在场感」，正好对应 mesh 里的节点）；等宽大写、宽字距的小标注；酸性绿 `#ceff1c`；CRT 闪烁、抖动、boop 的动效节奏 | 猫视频画布、整页只有一个图标的极简（我们是工具，要有信息密度） |
| [magpie](https://usemagpie.ai/) | 操作界面「一行一件事」：左边是谁、右边是取值；分组用等宽大写标注；筛选框 + 分段控件；流向图（Agent → 网关 → 供应商）；底部大数字计数 | 浅色主题、品牌图标墙 |
| [vibe42](https://vibe42.ai/) | 深色应用壳 + 侧栏；白色胶囊主按钮；双色大标题（第一行亮、第二行灰）；配对码格子；命令胶囊（图标 + 等宽命令 + 竖线 + 复制）；三步流程的大号细数字；加密链路图（中间节点用虚线框「只转发」） | 设备样机、营销式长页面 |

## 原则

1. **黑里只亮一点。** 猫眼绿只给三件事：**在线**、**本机**、**当前焦点和主操作**。一屏里亮的地方越少越好；热力图、图表、装饰都不许用绿色。
   填充用 `--eye`，写成字和细线用 `--eye-fg`（夜间两者相同，日间 `--eye-fg` 是橄榄色）。
2. **一个节点一只光标。** 每个节点有一只固定颜色的光标（`<Cursor>`），拓扑、列表、链路、凭据、配对预览里都是同一只。颜色只表示「是谁」，不表示状态。
3. **一行一件事。** 操作界面是列表，不是卡片墙。分组靠等宽大写标注（`<Cap>`），不用卡片套卡片。
4. **机器给的字用等宽。** IP、配对码、延迟、版本、peer id、命令一律 Geist Mono；人写的字用 Geist。命令和码都要能一键复制。
5. **只在变化时动。** 上线、断开、出码才有动效；常驻的只有光标的轻微漂移和在线点的脉冲。遵守系统的「减少动态效果」。

## Token

### 颜色

下表是夜间取值。日间见下一节「日间」。

| token | 值 | 用途 |
|---|---|---|
| `--void` | `#000` | 页面底、侧栏、拓扑画布 |
| `--ink-1`…`--ink-4` | `#0a0a0c` `#111114` `#18181c` `#222228` | 面板 → 卡片 / 输入框 → 悬停 → 按下。每层只亮一点 |
| `--line` `--line-2` `--line-3` | 白 7% / 12% / 22% | 分隔线、边框、虚线框 |
| `--fg` `--fg-2` `--fg-3` `--fg-4` | `#f2f2f3`、白 64% / 42% / 24% | 正文、次要、标注、占位 |
| `--eye` | `#ceff1c` | 在线点、本机、焦点环、主操作按钮、当前步骤 |
| `--warn` | `#ffb224` | 快过期（< 7 天）、丢包、内核迟滞 |
| `--bad` | `#ff5c49` | 断开、错误、危险操作确认态 |
| `--swarm-0`…`--swarm-5` | `#ff5b3a` `#ffc21a` `#2fd07f` `#3aa8ff` `#8b6cff` `#ff4f9a` | relay，按 `nodes.yaml` 顺序固定 |
| `--swarm-6`…`--swarm-9` | `#5ee6d0` `#d9b38c` `#e07bff` `#ffa47a` | 设备，按名字哈希；不会和 relay 撞色 |

控制台网关没有自己的颜色，用 `--gateway`（夜间 50% 白、日间 42% 黑；它是 surtr 上的一个进程，不是独立的节点）。

叠加层（热力图格子、点阵、径向渐变）不写死白色，写 `rgb(var(--tint) / a)`：`--tint` 夜间是白、日间是黑，同一个透明度在两种底上意思一样。

### 日间

`:root[data-theme="light"]` 覆盖一份取值，组件不用改。规则不变，只有这几处为了对比度做了取舍：

| token | 日间 | 为什么 |
|---|---|---|
| `--void` / `--ink-1`…`4` | `#f5f5f2` / `#fff` `#f3f3f0` `#ebebe7` `#e0e0db` | 纸白底、白面板。暖一点的灰，避免冷白刺眼 |
| `--fg-2` / `--fg-3` | 黑 66% / 55% | 夜间的 42% 换到白底上只有 3:1，标注提到 55%（4.3:1） |
| `--eye` | `#c6f432` | 只当**填充**：主按钮、路径上的延迟标签、选中文字底色。字是 `--eye-ink`（15:1） |
| `--eye-fg` | `#4f6b00` 橄榄 | 猫眼绿在白底上只有 1.2:1。写成字、细线、在线点、选中行竖线、焦点环时用这个（5.6:1） |
| `--warn` / `--bad` | `#966100` / `#da1700` | 压到 ≥4.6:1，能直接当字用 |
| `--swarm-0`…`9` | 每个色相压暗到在纸白上 ≥3:1 | 光标是图形，按非文字 3:1 算；色相顺序不变，同一个节点日夜是同一种颜色 |
| `--solid` | `#111113` | 主按钮从白胶囊变成黑胶囊 |

切换：顶栏右上角「跟随系统 / 日间 / 夜间」三态，选择存 `localStorage`（`mesh.theme`）；默认跟随系统。
`index.html` 里有一段内联脚本在首屏前就设好 `data-theme`，不会先黑后白闪一下。

### 字

- 界面：`Geist Variable`，中文回落 PingFang SC / Noto Sans SC。
- 机器：`Geist Mono Variable`，数字等宽（`tabular-nums`）。
- 字体随前端打包（`@fontsource-variable/*`），不走 CDN：控制台只在 overlay 上，不一定能出公网。

| 档 | 大小 | 用在 |
|---|---|---|
| `--t-cap` | 11px，等宽大写，字距 0.24em | 分组标注、统计标签、面包屑 |
| `--t-xs` | 12px | 行内次要信息、提示 |
| `--t-sm` | 13px | **操作界面正文** |
| `--t-md` / `--t-lg` | 14 / 16px | 面板标题、大按钮 |
| `--t-xl` | 22px | 抽屉标题 |
| `--t-2xl` | 32px | 统计大数字 |
| `--t-3xl` | 44px，字距 -0.03em | 页面双色大标题 |

### 形

- 圆角：标签 6、输入框 / 行 12、面板 16、按钮和命令胶囊全圆。
- 间距：4px 栅格（`--s-1`…`--s-16`）。
- 不用投影区分层级，靠底色深浅和 1px 线；只有抽屉和提示条有一层大投影。

### 动

| 名 | 时长 | 何时 |
|---|---|---|
| `blur-in` | 360ms | 换页、文字轮换、提示条出现 |
| `crt-flash` + `crt-jolt` | 640ms | 节点上线（配对成功）这种「状态跳变」 |
| `boop` | 360ms | 按钮按下 |
| `drift` | 6s 循环 | 光标常驻漂移 |
| `pulse-ring` | 1.8–2.6s 循环 | 在线点、本机光环 |
| `dash-flow` | 0.9s 循环 | 拓扑上本机到目标的路径 |

缓动统一 `--ease`（快进慢出）；弹一下用 `--ease-boop`。

## 组件

都在 `src/ui/`，页面只拼组件，不自己画按钮。

| 组件 | 用途 |
|---|---|
| `Mark` | 标志：六辐星号 = 六个接入点，中心一点是猫眼。`live` 亮、`connecting` 呼吸、`off` 熄灭 |
| `Cursor` | 节点身份光标 |
| `Button` | `eye`（一屏最多一个，最重要的动作）/ `primary`（白胶囊）/ `ghost` / `quiet` / `danger` |
| `ConfirmButton` | 危险操作点两次：第一次变红「再点一次确认」，3 秒不点复原。不用弹窗 |
| `Segmented` | 筛选、类型、有效期 |
| `Field` | 输入框；焦点时边框变猫眼绿 |
| `CommandPill` | 一行命令 + 复制；大号允许换行（配对码在命令末尾，不能被省略号吃掉） |
| `CodeBoxes` | 配对码格子，出码时逐格「解码」 |
| `Cap` / `Chip` / `StatusDot` / `Stat` / `Meter` / `KV` | 标注、标签、状态点、大数字、细条、键值行 |
| `List` + `Row` | magpie 式列表行；选中行左边一道猫眼绿 |
| `Drawer` / `Toast` / `Empty` / `Headline` | 右侧详情、底部提示条、空状态、双色大标题 |

## 版式

- 外壳：左侧 240px 纯黑侧栏（标志、网络名、导航、本机卡片、agent 版本），右侧顶栏只放面包屑和「几秒前更新」。
- 页面：最大 1320px，左右 40px。页头 = 标题 + 一句说明 + 右侧工具（筛选 / 分段 / 主按钮）。
- 总览：双色大标题直接说结论（「6 个接入点全部在线。」），下面一排大数字，再下面拓扑、链路、延迟矩阵。

## 文案

- 短句、陈述句，直接说结论；不用感叹号，不用「您」。
- 技术名词保留原文：WSS、SNI、secure mode、network_secret、latency_first。
- 状态写成事实：「内核没响应 · 127.0.0.1:15897」，不写「出错了，请稍后重试」。
- 每个错误都给下一步：缺什么参数、去哪个页面、复制哪条命令。

## 数据可视化

- **拓扑**：relay 按区域放在示意地图上（不是真实投影，保留南北东西关系）；设备绕着离它最近的 relay；连线透明度跟延迟走，越快越亮；悬停才显示每条边的延迟；本机到目标的实际路径用猫眼绿虚线流动。
- **延迟矩阵**：行 = 测量方，列 = 对端；白色单色顺序色阶（≤40 / ≤80 / ≤160 / ≤320 / >320 ms），**格子里一定写数字**，颜色只是辅助；悬停同时显示反向值。
- **细条**：剩余有效期、相对延迟；快过期变 `--warn`。

## 不做

- 日间不是另一套设计：不加新颜色、不换版式，只换 token 取值。夜间是默认和原型，新组件先在夜间做对，再到日间检查对比度。
- 不用渐变按钮、玻璃拟态卡片、emoji 图标。
- 不在热力图、图表里用猫眼绿。
- 日间不拿 `--eye` 当字色或细线（1.2:1 看不见），用 `--eye-fg`。
- 不让密钥进浏览器：agent 删掉 `credential_secret` / `network_secret` / 私钥，`node` 的配置原文不出 agent。

## 移植到菜单栏 App（SwiftUI）

`app` 以后换皮时直接抄这些值：底 `Color.black`，面板 `#111114`，线 `white.opacity(0.07)`，
强调 `#ceff1c`（只用于在线点和主按钮），字体 Geist / Geist Mono（随 App 打包），列表行高 44、圆角 12、按钮全圆。
